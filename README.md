# Révision Al-Manhaj Al-'Alamy A1 · Massalikul'ulum

Flashcards et jeux pour réviser le vocabulaire (المفردات et التراكيب) des 12 chapitres du livre A1.

- **Réviser** : flashcards à répétition espacée (أَعْلَمُ / لَا أَعْلَمُ).
- **Jouer** : quiz chrono (chapitres 1 à 3) et défi du jour.
- **Progrès** : niveaux, série de jours, parcours des chapitres, badges.

La progression est enregistrée dans le navigateur de chaque élève.

Fichiers : `index.html` (page), `quiz.js`, `game.js` (gamification), `cards.js` (vocabulaire), `emoji.js` (icônes Fluent Emoji de Microsoft, licence MIT), `logo.png`.
